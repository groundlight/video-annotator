# Video Optimization for Web Streaming

## Problem

Videos generated by OpenCV's `VideoWriter` typically have the MP4 `moov` atom at the end of the file. This causes browsers to be unable to read video metadata (duration, dimensions, etc.) without downloading the entire file first, resulting in:

- Blank video player (`readyState: 0`)
- No video playback until full download
- Poor user experience

## Solution

Videos are automatically optimized for web streaming after generation (if `ffmpeg` is installed). This moves the `moov` atom to the beginning of the file, enabling:

- Immediate metadata reading
- Progressive playback
- Seeking without full download

## Automatic Optimization

New videos generated through the webapp or CLI are automatically optimized **if `ffmpeg` is installed**.

### Installing ffmpeg

```bash
brew install ffmpeg
```

### Manual Optimization

If you need to optimize an existing video:

```bash
./optimize_video_for_web.sh input_video.mp4 [output_video.mp4]
```

Or use the debug endpoint to test with any video:

```
http://localhost:5001/api/debug/preview/test-video?path=/path/to/video.mp4
```

## Technical Details

The optimization uses `ffmpeg` with the `+faststart` flag:

```bash
ffmpeg -i input.mp4 -c copy -movflags +faststart output.mp4
```

- `-c copy`: No re-encoding (fast, preserves quality)
- `+faststart`: Moves moov atom to beginning

## Troubleshooting

If videos still don't play in the browser:

1. **Check if ffmpeg is installed**: `which ffmpeg`
2. **Check server logs**: Look for optimization messages
3. **Test with optimized video**: Use the debug endpoint with a manually optimized video
4. **Check browser console**: Look for video loading errors
5. **Verify file format**: Ensure the file is a valid MP4
